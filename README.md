# Vaibhav Portfolio v2 🚀

Welcome to **v2** of my personal portfolio—a highly interactive, visually striking, and performant web experience built with modern web technologies. 

## 🌟 Key Features

- **J.A.R.V.I.S. AI Assistant**: A fully integrated, client-side Command Console powered by the **Gemini 2.5 API**. Features a sleek Arc Reactor aesthetic, dynamic holographic light cone projections, speech microphone toggle, and a CricSphere outcome simulator. It provides 3rd-person markdown streaming responses just like a real AI companion.
- **Cinematic Experience & Animations**: Start off with an epic OS boot sequence loading screen featuring Matrix digital rain, CRT glitches, and progress tracking. The entire UI is upgraded with spotlight cards, seamless page transitions, and parallax grids.
- **Project Deep-Dives**: Explore case studies like the **Nexus** project with a fully redesigned 3D coverflow UI and rich markdown documentation.
- **Interactive Badges**: A complete overhaul of the certifications and badges page. Custom native cards extracted from Credly metadata, combined with advanced CSS Grid layouts and search/filtering.
- **Terminal Command Palette**: Navigate the app like a pro using the built-in fast terminal command palette.
- **Premium Blog & Heatmaps**: Upgraded blog readability, TOC tracking, dynamic Github heatmaps, and animated achievement numbers.

## 🛠️ Technology Stack

- **Framework**: [Next.js](https://nextjs.org) (App Router, Server Components)
- **AI Integration**: Gemini 2.5 API for the J.A.R.V.I.S. Command Console
- **Styling**: Modern UI / CSS Grid / Custom Animations
- **Deployment**: Vercel

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
